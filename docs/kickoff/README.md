# Kickoff documents

The original planning documents, written before any code. They are retained
because later work cites them by section: the F1 pass criterion, the mutation
operator list, the coverage denominator, the security rules for the certifier,
and the kill criterion all live here and are quoted rather than paraphrased
elsewhere.

They are planning artifacts, not results. The evidence is in `evidence/` and the
claims are in the top-level README.

| | |
|---|---|
| `01-PRD.md` | scope, the three headline numbers, kill criteria |
| `02-technical-architecture.md` | invariants, kernel rules, mutation operators, coverage design |
| `03-security-and-access.md` | rules governing anything pointed at an external endpoint |
| `04-cli-and-report-spec.md` | CLI surface and report design |
